# dumpster-lib

shared resources for [dumpster-dip](https://github.com/spencermountain/dumpster-dip), [dumpster-dive](https://github.com/spencermountain/dumpster-dive/), and [dumpster-duck](https://github.com/spencermountain/dumpster-duck/)

used to download, unzip, and parse wikipedia dumps, other wikimedia dumps, and 3rd-party mediawiki dumps.

written in nodejs, but aims to support deno/bun.
